# Timbavati Medical Services

Responsive React website for Timbavati Medical Services, covering occupational health, primary healthcare, wellness programmes, medical surveillance, and workplace safety services across South Africa.

## Run locally

Prerequisite: Node.js 18+ and npm.

```sh
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Deploy with GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. Open **Settings > Pages** in the repository.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The workflow in `.github/workflows/deploy-pages.yml` will build and publish the site after each push to `main`.

The published address will be:

```text
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```
